The Glitch
Effect

Three layers of the same text stacked with position:absolute. The ::before and ::after pseudo-elements use clip-path to show only slices, then CSS keyframes offset them horizontally to simulate digital corruption.

::before { clip-path: polygon(0 0, 100% 0, 100% 35%, 0 35%) }
::after  { clip-path: polygon(0 65%, 100% 65%, 100% 100%, 0 100%) }
