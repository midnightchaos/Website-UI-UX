CSS / RADIAL-GRADIENT

Gradient
Mesh Animation

Pure CSS technique using multiple layered radial-gradient() functions with different ellipse positions. Animated with @keyframes and blurred with filter: blur() to create smooth, organic color transitions with zero JavaScript rendering.

/* The magic — stacked radial gradients */
background:
  radial-gradient(ellipse 60% 60% at 20% 30%, rgba(255,60,0,0.7) 0%, transparent 70%),
  radial-gradient(ellipse 50% 50% at 70% 20%, rgba(255,170,0,0.6) 0%, transparent 70%);
filter: blur(40px) saturate(1.4);
animation: meshPulse 12s ease-in-out infinite;
